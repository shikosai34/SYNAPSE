# 当日運用マニュアル（サークル管理）

最終更新: 2026-10-05
対象: サークル責任者、サークルスタッフ
関連: [イベント管理マニュアル](./当日運用マニュアル_イベント管理.md)

## この画面で行うこと

サークルのメニュー、在庫、売上、メンバー、運用設定を管理します。サークル管理画面は `/circle/dashboard` です。ヘッダーのスペース切り替えで対象サークルを選択してください。イベント全体の設定・スタッフ・全体売上はイベント画面の担当です。

## 開場前チェック

1. ヘッダーと画面タイトルで対象サークルを確認します。
2. 「サークル設定」で注文モード、対応する支払い方法、必要な拡張機能を確認して保存します。
3. 「メニュー管理」で商品名、価格、説明、販売状態、オプションを確認します。
4. 在庫を使う商品は「在庫管理」で販売数と在庫数を確認します。売り切れ表示を練習用に切り替えたままにしていないか確認します。
5. 「メンバー管理」で当日の責任者・担当者が有効なメンバーか確認します。スタッフ機能を使う場合は「スタッフ管理」も確認します。
6. 「モバイルオーダーQR」を開き、掲示するQRが対象サークルのものか確認します。印刷・掲示前に一度スマートフォンで読み取ります。

## 開催中の基本手順

### メニュー・在庫の変更

1. 販売を一時停止する場合は「メニュー管理」で該当商品を特定し、販売状態を変更します。
2. 在庫数を数え直す場合は「在庫管理」で実数に合わせます。画面上の残数だけを見て実物の在庫を推測しないでください。
3. 保存後、来場者向け注文画面またはQRから商品が販売停止・売り切れとして見えることを確認します。
4. 商品名・価格を変更したときは、注文済み分や店頭掲示と食い違わないよう担当間で共有します。

### 注文と売上を確認する

1. 注文の受付・調理・受け渡しは、割り当てられた店頭運用端末で行います。
2. サークル管理の「売上管理」では、営業日を選び注文一覧と完了注文の合計を確認します。初期表示は注文がある日のうち最新日です。
3. 集計値に疑問があれば「統計・分析」でも注文数、完了率、商品別・時間別の集計を確認します。
4. イベント全体の注文遅延、全体の売上、リストバンド問い合わせはイベント担当者へ連絡します。

### 来場者への案内

- QRはサークルごとに異なります。隣のサークルのQRと取り違えないよう、掲示物にサークル名を大きく表示します。
- クーポンやレビュー、統計エクスポートは目的の画面を確認してから操作します。来場者向けリンクと管理者用画面のURLを混同しないでください。
- 注文方法や支払い方法が変更された場合、画面の設定だけで案内が完了したと考えず、店頭掲示・担当者への共有も更新します。

## 終了時

1. 店頭の担当者が注文の受け渡し・未完了注文を確認します。
2. 「売上管理」で当日の対象日を選び、完了注文数と売上を確認します。
3. 必要な場合は「統計・分析」または「データエクスポート」でCSVを保存し、会計責任者へ渡します。CSVには来場者情報等が含まれる場合があるため、共有先を限定してください。
4. 在庫数・売り切れ表示を実物と照合します。
5. サークルの責任者がイベント運営へ終了を報告します。サークルの「売上管理」はイベント全体の受付停止・日次締めを行う画面ではありません。

## サークル画面の一覧

| メニュー | 用途 | 注意点 |
|---|---|---|
| ダッシュボード | サークルの概要 | 対象サークル名を確認 |
| モバイルオーダーQR | 注文用QRの表示 | 掲示前にサークル名と遷移先を確認 |
| メニュー管理 | 商品・価格・販売内容の管理 | 更新後に来場者側の表示を確認 |
| 在庫管理 | 在庫数・売り切れの管理 | 実物の数と定期的に照合 |
| 売上管理 | 日別の注文・売上確認 | 主に完了注文を売上として計上 |
| 統計・分析 | 注文数、完了率、商品・時間帯の集計 | LIVEを有効にすると約15秒間隔で再取得 |
| レビュー | 来場者レビューの確認 | 返信・対応はサークル責任者が判断 |
| データエクスポート | サークルデータの出力 | 個人情報を含む場合の保管・共有に注意 |
| クーポン管理 | クーポンの発行・確認 | 適用条件と有効期間を案内と一致させる |
| サークル設定 | 基本情報・注文モード・支払い等 | 「基本情報」と「運用設定」は別々に保存 |
| メンバー管理 | メンバー・招待・権限の管理 | 最後の管理者を無効化・降格できない |
| スタッフ管理 | 店頭スタッフの管理 | サークル設定のスタッフ機能が有効な場合に表示 |

## 間違えやすい内部仕様・トラブル対応

- **保存ボタンを押したのに一部が戻る**: サークル設定は「基本情報」と「運用設定」で保存範囲が分かれています。サークル名・説明・画像は基本情報の保存ボタン、注文モード・拡張機能・支払い方法は「運用設定を保存」を押してください。片方の保存で他方も保存されるわけではありません。
- **イベントで支払い方法を追加・削除した**: サークルが選べる対応方法はイベント側の支払い方法が上限です。イベントから削除された方法は、サークルの設定保存時に除外されます。イベント側を先に確定し、その後サークル側の対応方法を確認してください。
- **スタッフ管理が見えない**: スタッフ機能が無効だとメニューが表示されません。サークル責任者が「サークル設定 > 運用設定」で有効化し、保存してください。
- **在庫数があるのにイベント画面の在庫少数に出ない**: 在庫少数の集計対象は在庫管理が有効なサークルの商品です。商品側で在庫管理が有効か、売り切れ状態ではないか、数量が正しく保存されたかを確認してください。
- **売上が注文数と合わない**: 売上管理の金額は完了注文を基準にします。未着手・処理中・キャンセル等を含めた件数とは一致しません。統計の総注文数と完了率も合わせて見てください。
- **表示が古い**: 統計画面のLIVEは初期状態で無効です。有効にすると約15秒ごとに再取得します。売上管理は必要に応じて画面を再読み込みして最新状態にしてください。
- **別サークルの数字・設定に見える**: スペース切り替え直後はヘッダーと画面タイトルを再確認します。所属を切り替えると対象データを再取得しますが、作業前にサークル名を確認するのが安全です。
- **画面が読み取り専用になった**: イベントが終了・アーカイブ状態の場合、サークル画面も変更できません。サークル側で解除できないため、イベント責任者へ連絡してください。
- **オーナーを交代する**: 「サークル設定」のオーナー譲渡は権限を移し、譲渡元は一般スタッフになります。対象者の氏名を確認してから確定してください。
