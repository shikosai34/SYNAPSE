# 非公式クライアントを開発・利用したい方へ

FesFlow の画面や操作を、イベント当日の運用に合わせたクライアントから利用したい方へ。

SYNAPSE のソースコードは GitHub で公開しており、どなたでも閲覧できます。使いやすさの改善や新しいクライアントの実装など、変更案は Pull Request（PR）として提案できます。

- リポジトリ: <https://github.com/shikosai34/SYNAPSE>
- ローカル開発ガイド: [docs/DEVELOPMENT.md](./DEVELOPMENT.md)

## 開発を始めるには

まず、どの利用者が当日どの作業を行うためのクライアントなのかを整理してください。来場者向け、模擬店スタッフ向け、イベント運営向けでは、必要な画面や権限が異なります。

ローカル開発ガイドに沿って開発環境を起動し、デモデータを使って動作を確認できます。既存画面や API の仕様を確認したい場合は、リポジトリ内の `apps/` と `packages/`、設計資料を参照してください。変更を共有する際は、実現したい運用、対象ユーザー、確認した操作手順を PR に記載してください。PR は歓迎しますが、内容の確認や取り込みにはレビューが必要です。

## 当日利用を計画するとき

非公式クライアントを本番環境や実際の来場者データに接続する前に、イベント運営担当者へ利用目的、対象者、取得・更新するデータ、障害時の対応を共有し、接続方法と利用可否を確認してください。公開リポジトリを閲覧できることや PR を作成できることは、本番環境への接続許可や公式サポートを意味しません。

当日の運用では、次の点を事前に確認してください。

- 認証・権限の仕組みを迂回せず、利用者に必要な権限だけを使う。
- アカウント情報、Cookie、API キーなどの認証情報を共有・公開せず、ソースコードや PR に含めない。
- 実データを開発・検証目的で持ち出さず、ローカル環境ではデモデータを使う。
- 通信障害やクライアントの不具合が起きた場合の連絡先と、既存画面などへの切り替え手順を用意する。
- API や画面の仕様は変更される可能性があるため、当日までに実際の利用環境で動作を再確認する。

非公式クライアントの開発・運用は利用者自身の責任で行ってください。運営側での利用確認や PR のレビューを希望する場合は、まず [GitHub の Issue](https://github.com/shikosai34/SYNAPSE/issues) で目的と利用予定を共有してください。

## コードの利用について

ソースコードの閲覧や変更案の PR は歓迎します。リポジトリが公開されていることは、コードの再利用・再配布の許諾を意味しません。コードを再利用・再配布する場合は、事前に運営へ確認し、各依存パッケージのライセンス条件も確認してください。
