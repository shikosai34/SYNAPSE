（以下「当方」といいます）は、学園祭・イベント向けプラットフォーム「FesFlow」（以下「本サービス」といいます）における個人情報等の取り扱いについて、次のとおりプライバシーポリシーを定めます。

## 1. 取得する情報

当方は、本サービスの提供にあたり、次の情報を取得します。取得する情報は、本サービスに実装されている機能に基づきます。

### (1) イベント運営者・サークルの管理者等のアカウントに関する情報

- Google アカウントによる認証に伴い取得する情報（メールアドレス、氏名・表示名等、認証に必要な範囲の情報）。本サービスは Google アカウントによる認証およびパスキーを利用しています。
- イベントの契約に関する情報（契約担当者のメールアドレス、プラン・契約状態等）

### (2) 来場者に関する情報

- オンボーディング（利用開始登録）の際に入力する情報：ニックネーム、誕生日（リストバンド紛失時等の本人確認のために取得します）
- 属性・統計に関する情報：年代等の区分（個人を特定しない統計の作成に用います）
- リストバンドとの紐付け情報：リストバンド ID と来場者アカウントの対応関係
- 注文に関する情報：事前注文・モバイルオーダーの内容、金額、注文状態、受け取り履歴
- 機能の利用履歴：スタンプラリーの取得状況、抽選への参加・結果、クーポンの利用、レビューの投稿内容
- 通知に関する情報：Web Push 通知の購読に必要な端末・ブラウザの情報（購読を許可した場合）
- アクセスに伴い自動的に取得する情報：IP アドレス、ブラウザ・端末情報、アクセスログ等

### (3) 決済に関する情報

- 有償プランの支払いが銀行振込・請求書払いの場合：請求および入金確認に必要な情報
- クレジットカード決済（Stripe）を利用する場合：決済は決済事業者（Stripe）が処理し、当方はカード番号そのものを取得・保持しません。決済の識別に必要な情報（顧客 ID 等）を保持します。※Stripe 決済は本書作成時点で未実装であり、実装後に本項を適用します。

## 2. 利用目的

取得した情報は、次の目的で利用します。

1. 本サービスの提供、本人確認、アカウント管理のため
2. 注文受付、スタンプラリー、抽選、クーポン等の各機能を動作させるため
3. リストバンド紛失時の本人確認および再発行のため
4. イベント運営者による当日の運営（混雑状況の把握、注文管理、会計・精算、売上集計等）を支援するため
5. イベント全体の統計（年代別等の集計を含む、個人を特定しない形の統計）の作成および運営者への提供のため
6. 有償プランの料金請求、入金確認、契約管理のため
7. お知らせ・通知の配信、不正利用の防止、障害・セキュリティ対応のため
8. 本サービスの改善、新機能の検討のため

## 3. イベント運営者との情報の共有

来場者の情報（ニックネーム、注文情報、スタンプ取得状況等）は、参加したイベントの運営者（および当該イベントのサークル）が、当該イベントの運営に必要な範囲で、本サービス上で閲覧・利用できます。運営者は、取得した情報をイベント運営以外の目的で利用しないものとし、その取り扱いについては利用規約および関係法令に従うものとします。

## 4. 第三者提供

当方は、次の場合を除き、取得した個人情報を第三者に提供しません。

1. 本人の同意がある場合
2. 法令に基づく場合
3. 人の生命、身体または財産の保護のために必要で、本人の同意を得ることが困難な場合
4. 本サービスの基盤として利用する外部サービス（クラウドインフラ事業者等）に、サービス提供に必要な範囲でデータの保存・処理を委託する場合。この場合、委託先はデータの保管・処理のためにのみ情報を取り扱います。

## 5. データの保持と削除

1. イベントに関するデータは、イベント終了後も一定期間保持します。保持期間は、イベントごとの設定（実装上の既定は終了後365日、変更可能な範囲は30〜3,650日）によります。
2. **現在の制約（重要）**：保持期間経過後の自動削除の仕組みは実装されていますが、本書作成時点では本番環境で有効化されておらず（検証モードのまま）、自動削除は実際には行われていません。そのため現時点では、期間経過後のデータも当面保持されます。自動削除を有効化した場合は、その旨を本ポリシーに反映します。
3. 来場者情報の削除は、参加したイベントの運営者が本サービスの管理機能から行うことができます。また、本人から当方への削除の申し出があった場合は、第7項の窓口で受け付け、運営者と連携のうえ対応します。
4. 統計データについては、個人を特定できない形に加工したもの（年代別の注文件数等）を、来場者個人の情報を削除した後も保持することがあります。

## 6. 安全管理

当方は、個人情報の漏えい、滅失、毀損の防止その他の安全管理のため、アクセス権限の管理（イベント・サークル単位の権限分離）等の措置を講じます。ただし、インターネット上の通信およびシステムの完全な安全性を保証するものではありません。
