## 2. 学生が個人事業として販売する前提での注意点

1. **開業の手続き**: 継続的に有償で販売する場合は、個人事業の開業届（および必要に応じて青色申告承認申請）の提出を検討してください。税務上の取り扱いは税務署または税理士に確認してください。
2. **住所・電話番号の公開**: 特定商取引法の表記では、販売業者の住所・電話番号の記載が求められます。個人の自宅住所や私用電話番号を公開することになるため、公開範囲を理解したうえで判断してください。電話番号については「請求があった場合に遅滞なく開示する」旨を記載する方法が認められる場合がありますが、住所については実際の住所の記載が原則です。バーチャルオフィス等の利用可否を含め、消費者庁のガイドラインで最新の運用を確認してください。
3. **未成年の場合**: 販売者が未成年の場合、法定代理人（保護者）の同意がない契約は取り消され得ます。該当する場合は、事前に法定代理人の同意を得てください。
4. **学校との関係**: 学校行事の一環ではなく個人の事業として販売する位置づけを、対外的に一貫させてください（学校名を冠した販売に見える表示は避ける等）。学校の名称・ロゴの使用は学校の許可範囲を確認してください。
5. **決済手段の準備**: Stripe 等の決済サービスの利用には、本人確認と事業情報の登録が必要です。個人事業として登録する場合の記載内容は、本表記の内容と一致させてください。

## 3. 関連する注意（イベント内の販売について）

- FesFlow を通じた来場者への事前注文は、法務リスク分析（`docs/legal_risk_analysis.md`）において、特定商取引法の「通信販売」に該当する可能性があると指摘されています。売主である各イベント運営者・サークル側でも表記が必要になる場合があるため、導入ガイド等で運営者にその旨を案内することを推奨します。
- 来場者から金銭を預かる仕組み（ポイント・チャージ残高等）は、資金決済法上の前払式支払手段に該当し得るため、現行の「現地決済の予約」モデルを変更する場合は事前に法務確認が必要です。
